# TestQuest — SQL тестовые задания и курс

Репозиторий содержит тестовые задания по SQL (PostgreSQL) уровней Junior и Middle
на тему биллинга ЖКХ (база данных `ISERVDB`), а также интерактивный курс,
объясняющий устройство решений.

## Содержимое

- `Тестовое задание pg sql J_M/` — условия заданий, скрипт создания БД (`iservdb.sql`),
  описание схемы, решения `Junior solution.sql` / `Middle solution.sql` и эталонные скриншоты.
- `iservdb-course/` — интерактивный HTML-курс «Как работает биллинг ЖКХ».
  Открыть: `iservdb-course/index.html` в браузере (работает офлайн).

## Запуск заданий

1. Создать БД и схему скриптом `Тестовое задание pg sql J_M/.../Скрипт iservdb.sql`.
2. Выполнить функции из `Junior solution.sql` и `Middle solution.sql`.
3. Проверить результаты по скриншотам из папки `img/`.
