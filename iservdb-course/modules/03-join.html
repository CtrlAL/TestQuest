Как детали общаются

JOIN склеивает папки по общему ключу — как сверка двух ведомостей

Что такое JOIN

Чтобы собрать отчёт, базе нужно соединить людей со их счетами. Операция JOIN берёт строки из одной папки и приклеивает к ним подходящие строки из другой.

Метафора: у тебя две тетради — в одной имена учеников, в другой их оценки. По «номеру ученика» ты подписываешь каждой оценке нужное имя. Результат — одна таблица «имя + оценка».

Код склейки, слово в слово

Вот реальный кусок из функции rpt_subscrs_debts_by_term — именно он соединяет клиента со счетами:

CODE 
FROM dbo.sd_subscrs s
JOIN dbo.fd_bills b ON b.f_subscr = s.link
WHERE s.link = _f_subscr
  AND b.d_date <= _d_date
PLAIN ENGLISH

Начинаем с папки лицевых счетов (назовём её буквой s).

Приклеиваем к каждому счёту (b) строку, где владелец счёта совпадает с клиентом.

Оставляем только того клиента, которого попросили.

И только счета, выписанные не позже указанной даты.

💡
Ключевая мысль

JOIN — это не «слияние двух таблиц в одну навсегда», а взгляд на них рядом, только на время одного запроса. Исходные папки не меняются.
